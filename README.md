# Oh Machi (町)

Oh Machi is a cozy, peer-to-peer pixel-town simulator in the spirit of *Animal Crossing*: each player is a pixel-art character with their own lot in a shared neighborhood, where a local AI agent builds houses, yards, props, and outfits from constrained pixel-art and image-generation tools. Neighbors discover each other without a central game server, share signed assets peer to peer, and chat in real time. The project targets friendly Linux desktops (including [Omarchy](https://omarchy.org/)), but is not Omarchy-specific.

**Status:** Design phase — no playable client yet. Architecture, milestones, and asset format are documented below.
